# BharatGuide UX Mockup

## 1. Design Objective
Create a premium, trust-focused travel discovery experience that feels warm, local, and emotionally resonant. The design should communicate authenticity, local connection, and ease of action without overwhelming the user.

## 2. Visual Direction
### Style
- Warm neutral backgrounds with earthy tones
- Saffron, green, and natural stone-inspired accents
- Clean serif headings for premium editorial identity
- Simple sans-serif body type for clarity and readability

### Brand Feel
The UI should feel like a modern Indian travel brand that blends heritage, hospitality, and modern convenience.

## 3. Key Screens

### A. Landing / Hero Screen
**Purpose:** Introduce the value proposition quickly.

**Layout components:**
- top utility bar
- brand header
- navigation links
- large hero headline
- supporting copy
- call-to-action button or link
- local image visual with destination tag
- social-proof / trust strip below

**Core message:** “Find your kind of India.”

### B. Guide Discovery Screen
**Purpose:** Help users find a local guide by city and interest.

**Layout components:**
- destination filter dropdown
- category chips
- guide cards with image, city, rating, languages, and price
- CTA button per guide card

**Behavior:**
- Selecting a city filters results instantly
- Selecting a category narrows the guide list
- Empty state appears when no guide matches

### C. Booking Request Modal
**Purpose:** Convert intent into a booking request.

**Layout components:**
- guide title and location
- guide price summary
- form fields for name, date, guest count
- request submission button
- demo disclaimer text

**Tone:** reassuring, clear, low-friction

### D. Confirmation State
**Purpose:** Validate action completion.

**Layout components:**
- success icon
- confirmation headline
- personalized thank-you message
- reference ID or demo code
- final CTA to close the flow

## 4. UX Principles
- Keep actions visible and obvious
- Make trust signals prominent
- Reduce form friction
- Match content to emotional motivations of travel
- Maintain strong visual hierarchy

## 5. Screen Flow
Home -> Explore -> Guide selection -> Booking request -> Confirmation

## 6. Mobile Experience
The mobile layout should prioritize:
- single-column guide cards
- sticky or compact header controls
- tap-friendly booking actions
- readable category chips
- minimal form friction

## 7. Design Notes
- Use strong destination photography to trigger travel emotion
- Keep the content grounded in real local storytelling rather than generic tourism copy
- Use a premium but not intimidating tone
- Avoid overloading users with too many controls on first screen

## 8. Recommended Future UX Enhancements
- personalized destination recommendations
- location-based guide suggestions
- chat preview for planning before booking
- guide dashboard for onboarding and schedule management
- review and rating display after trip completion
